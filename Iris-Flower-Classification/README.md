# Iris Flower Classification

This project is a Machine Learning model that classifies Iris flowers into different species based on their sepal and petal measurements.

## Project Description

The Iris Flower Classification project is one of the most popular introductory machine learning classification tasks. The objective of this project is to analyze flower measurements and build a classification model capable of accurately predicting the species of an Iris flower.

The dataset contains 150 flower samples belonging to three different species:

* Iris Setosa
* Iris Versicolor
* Iris Virginica

Each flower sample is described using four numerical features related to its sepal and petal dimensions.

## Features Used

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width
* Species (Target Variable)
